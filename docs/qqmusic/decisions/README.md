# QQ Music Architecture Decisions

These records define the active contracts that bound QQ Music native
development. Browser-based sign-in design records were retired when the product
returned to a single-process Qt 5 boundary.

- ADR-001: repository, platform, and evidence boundaries
- ADR-005: logging, Cookie metadata, and Secrets
- ADR-006: normal desktop launch and Ambience integration
- ADR-007: build, package identity, and rollback
- ADR-008: single-process Qt 5 QR login
